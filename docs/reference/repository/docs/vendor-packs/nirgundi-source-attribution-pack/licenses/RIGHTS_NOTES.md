# Source rights notes

## Nighaṇṭu — Sanskrit Library, 2010
The catalogue explicitly states Copyright © 2010 The Sanskrit Library and a Creative Commons Attribution-NonCommercial-ShareAlike 3.0 licence. Any redistributed adaptation must be attributed and shared under the same licence. NonCommercial is a material restriction. Do not describe this source as commercially reusable.

## CDSL csl-orig
The repository identifies CC BY-SA 4.0. Attribute the Cologne Digital Sanskrit Dictionaries project and the specific dictionary/source revision. If distributing adapted material, observe ShareAlike. Keep the source licence separate from the Pushkalāvatī software licence.

## Amarakośa / SanskritDocuments
The catalogue offers text, scans, and multiple editions, but the reviewed catalogue page does not establish a blanket licence for every asset. The ancient underlying work and a modern transcription/edition are distinct rights questions. Do not redistribute an asset until its own rights are established.

## GRETIL / Nirukta
GRETIL aggregates texts from different contributors and institutions. Do not infer a universal licence. Verify the particular text's source, contributor, edition, and terms.

## NIIMH/CCRAS e-Nighantu
The site displays an “All Rights Reserved” notice. Treat the online database as non-redistributable absent separate permission. A public interface is not an open data licence.

## Operational policy
- Bundle only sources with an identifiable permission basis.
- Preserve upstream notices, source revision, and SHA-256.
- Never claim an ancient underlying text automatically makes a modern digital edition public domain.
- Keep links and acquisition instructions for rights-unresolved sources rather than repackaging their content.
