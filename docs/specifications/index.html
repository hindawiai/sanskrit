Evidence labels

Documented: named by historical HPS documentation or project descriptions. Specification target: minimum contract proposed for maintainable implementations. Unverified: exact grammar, syntax, command pipeline, or runtime not confirmed from source in this checkout. These labels prevent a proposed specification from being mistaken for recovered historical implementation.
