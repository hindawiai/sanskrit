# IKS licensed test corpus and source pack

Prepared 2026-10-09.

## Included
- Transcription of the official IKS Division standard licensing notice dated 27 February 2025.
- Relevant transcription of the official licensing FAQ.
- A small text fixture derived from the notice for pipeline smoke tests.
- Source registry and attribution/rights notes.

## Important limitation
The official PDF URLs were verified, but direct binary downloads failed in this environment. This package therefore includes text transcriptions, not the original official PDF files. The official URLs are retained so the originals can be downloaded and checked locally.

This is **not** a complete IKS corpus. IKS is a broad domain spanning many traditions, languages, editions, institutions, and repositories. No single comprehensive corpus with one blanket licence was identified. The Union Catalogue of the Corpus of Indian Knowledge is a discovery catalogue of source texts/manuscripts, not a bundle of all full texts. E-Bharatisampat is a large digital library, but individual text rights vary.

## Licence
The IKS Division's public notice dated 27 February 2025 states that the standard licensing format for all IKS publications is Creative Commons Attribution-ShareAlike (CC BY-SA). Its FAQ states that attribution is required, commercial reuse is permitted, and adaptations must be shared under the same terms.

Because the notice itself does not state a version number, this pack links to CC BY-SA 4.0 as the current reference and advises checking the specific publication's licence statement. Do not assume this policy covers every third-party text merely linked from the IKS website.

## Use for Nirgundi
`corpus/iks_license_notice_test.txt` is suitable for testing ingestion, offsets, hashing, and residual-preservation mechanics. It is English and is **not** a Sanskrit lexical-coverage benchmark. For a meaningful Nirgundi Sanskrit test, select a specific Sanskrit work whose individual edition/transcription has an explicit reusable licence, then preserve its source metadata and exact text.
