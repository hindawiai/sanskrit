Required release gates

  1. Pin upstream Romenagri commit and preserve source license/notices.
  2. Compile original C library and all conversion utilities with warnings enabled.
  3. Compare JS adapter against C implementation on table entries, valid strings, malformed input, and round-trip corpus.
  4. Run original sed filter against fixed Urdu/Hindi fixtures and assert exact output.
  5. Build every supported HPS frontend/backend pipeline from documented scripts.
  6. Run root regression suite and browser smoke tests on GitHub Pages.
  7. Confirm unsupported scripts/sounds fail explicitly rather than silently degrade.

Current checkout

  • Existing root suite: ./scripts/test_all.sh.
  • Compiler inventory: 3,983 source records; 12 executable-tested operations in this baseline.
  • One Python test is known to skip when external MW/RV experiment artifacts are absent.
  • Full upstream Romenagri source was not available in the offline build environment. The vendoring script exists but actual C/sed compilation and differential tests remain release blockers.
  • Browser application is a static demonstrator, not a replacement for native compiler execution.

Regression invariants

  • No record is marked executable merely because it parses or serializes.
  • Statuses remain explicit: APPLIED, NOT_APPLICABLE, UNRESOLVED, ERROR.
  • Longest-match sound tokenization must preserve diphthongs and aspirates.
  • Legacy ACII table-key presence must not be mistaken for full word encoding.
  • Inverse analysis preserves competing candidates and does not invent suffix morphology.
