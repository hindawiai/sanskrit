SHARED CONVERSION SUBSTRATE

Romenagri

Specification index

Source-derived facts

  • The upstream source defines ACII-to-Romenagri and Romenagri-to-ACII conversion routines and a table of 84 entries including a control sentinel.
  • The table mixes syllabic consonant-with-inherent-vowel keys, independent-vowel/mātrā keys, special markers, and compound sequences.
  • The legacy Unicode converter uses UTF-16-like two-byte code units; it is not a general UTF-8 decoder.
  • The project repository describes a Perso-Arabic data layer including Urdu/Arabic mappings and an Urdu↔Hindi filter named fltr_ur_hi.
  • The upstream README labels the published repository as a seed release and calls out hardening work. Its measured reversibility figure is specific to the README's arbitrary [a-z] test, not a universal language-coverage guarantee.

Source: project-ilm/romenagri; lineage: hindawiai/chintamani/Romenagri.

Required layers

  1. Input decoding and Unicode normalization with explicit error handling.
  2. Romenagri textual/phonetic representation and parser state.
  3. Legacy ACII conversion table, kept distinct from Unicode and phonological token IDs.
  4. Script-specific maps, including Perso-Arabic-family mappings.
  5. Original sed-based Urdu/Hindi filter preserved as source data and executed unchanged.
  6. Round-trip and canonicalization metadata, including ambiguity/error status.

Integration contract

Pushkalāvatī's grammatical IR consumes canonical Sanskrit sound tokens, not legacy display bytes. Every bridge must provide explicit source/target encoding, provenance, reversible/ambiguous status, and test vectors. Unsupported sounds cannot be silently approximated.

Release gates

  • Vendor pinned upstream source and license notices.
  • Compile C converters with diagnostics enabled.
  • Byte-for-byte differential tests against the original library.
  • Fixtures for Devanagari, Perso-Arabic, punctuation, mixed scripts, unknown characters, malformed Unicode, and round-trip ambiguity.
  • Execute original sed filter against checked-in expected outputs.
