Sūtram

Specification index

Purpose

Sūtram is the repository's rule-rewrite language prototype. It is distinct from the full Aṣṭādhyāyī and from Pushkalāvatī's corpus compiler.

Current JavaScript subset

  • Scopes: adhyaya, pada, adhikara, closed by iti.
  • Operations: karta, yoga, viyoga, dviguna, likh, phala, unary calls.
  • Literals: integers, laghu/guru, netra, veda; parameters and Unicode identifiers in the JS parser.
  • Execution uses state-transition rewrite rules and precedence; the tested subset is not a general-purpose production language.
