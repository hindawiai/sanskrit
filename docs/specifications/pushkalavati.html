SANSKRIT COMPILER

Pushkalāvatī

Specification index

Purpose and scope

Pushkalāvatī is a source-grounded compiler and rule-execution research system for Pāṇinian grammar. The current corpus index contains 3,983 records. That count is an inventory size, not the number of implemented rules.

Representation

  • Source record: stable sūtra ID, Sanskrit text, type, padaccheda, anuvṛtti and gloss as available.
  • Functional classification: overlapping categories, with uncertain annotations explicitly reviewable.
  • Rule IR: preconditions/context, operation, postcondition/output, source provenance, test vectors, and lifecycle status.
  • Sound substrate: Unicode input/output at boundaries; canonical token arrays for rule execution; Romenagri ACII keys only where audited.
  • Inverse reduction: candidate generation, trace, and ambiguity preservation; not an unrestricted morphology parser.

Execution statuses

APPLIED, NOT_APPLICABLE, UNRESOLVED, and ERROR must remain distinct. Only source-grounded operations with positive examples and negative applicability tests may be labeled executable_tested.

Current baseline

  • 12 executable-tested operations in the rule-12/6.1.94 baseline.
  • 3 derivable but untested records.
  • Full semantic interpretation of all 3,983 records remains incomplete.
  • Full Sanskrit morphology, kāraka/syntax, complete sandhi parity, and full self-hosting are not yet complete.
