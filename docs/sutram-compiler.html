Browser-side compiler for the documented Sūtram subset. It generates standalone C and Rust source; the browser does not contain a native C/Rust compiler.

1 · Sūtram → C / Rust

Supported: adhyaya, pada, adhikara, integer/laghu/guru/netra/veda literals, one positional parameter, karta, yoga, viyoga, dviguna, likh, phala, and non-recursive unary calls.

Choose a target.

2 · Raise restricted C / Rust → Sūtram

This is a deliberately narrow reverse frontend. It accepts straight-line integer karta code, constant addition/subtraction, doubling and printing. Unsupported control flow, pointers, APIs and types are rejected. It is not a general C or Rust parser.

Raised Sūtram will appear here.

Native compilation contract

  • CLI: node lang/js/backend.js lang/examples/ganana.su c mula > /tmp/ganana.c
  • Compile and run C: gcc -std=c11 -Wall -Wextra -Werror /tmp/ganana.c -o /tmp/ganana && /tmp/ganana
  • Generate Rust: node lang/js/backend.js lang/examples/ganana.su rust mula > /tmp/ganana.rs
  • Rust release gate: rustc --edition=2021 -D warnings /tmp/ganana.rs -o /tmp/ganana-rs, then compare stdout/result to the JS interpreter. rustc was unavailable in the build environment and has not been marked compiled.
