Specification index

Do not conflate two axes

HPS language families (C-like, C++-like, BASIC-like, LOGO-like, assembly, lexer/parser generators, JVM-targeted language) are one axis. Natural language and script edition (Hindi/Devanagari, Bangla/Bengali, Gujarati, Assamese, Nepali, and other reported targets) are another. Each pair needs its own mapping and test corpus; a language's availability does not imply every compiler family has been ported to it.

Required matrix for each release

For every natural-language/script × programming-language pair, record: source edition/version; script encoding; Romenagri/ACII mapping version; filter pipeline; source grammar/keyword dictionary; target language; backend versions; compile command; golden source/output fixtures; known unsupported constructs; and license/provenance.
