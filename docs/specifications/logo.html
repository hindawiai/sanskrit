HINDAWI LANGUAGE SPECIFICATION

Shaili Robot (LOGO-like programming interface)

Educational/turtle programming · Specification index · Open browser lab · Historical references

Historical scope

Contemporary public documentation identifies the Hindawi LOGO frontend as Shaili Robot. The current browser lab is a newly implemented, bounded LOGO-like subset, not a verified reproduction of the historical frontend. Recover command vocabulary, turtle state model, graphics primitives, control structures, and runtime from historical source. Do not assume BASIC syntax: Shaili Prathmik is the separate Hindi BASIC-like language; Shaili Robot is the LOGO-like/robot-programming interface.

Compilation pipeline

Target pipeline: localized LOGO source → Romenagri normalization → LOGO translator/runtime → graphics execution. Exact translator and command sequence are UNVERIFIED.

Required specification artifacts

  • Source grammar and versioned keyword/token inventory.
  • Native-script and Romenagri test fixtures, including round-trip and ambiguity cases.
  • Frontend invocation, generated intermediate/source form, and exact backend tool versions/flags.
  • Positive, negative, diagnostic, and regression test suites.
  • Feature matrix distinguishing supported, partial, unsupported, and unverified features.
  • License, provenance, and original-source links.

Evidence status

The historical family/target is documented. The detailed contract above is a recovery and maintenance specification; it is not represented as a verbatim recovered grammar. Mark individual features verified only after inspecting and building the corresponding upstream source.
