Project identity and language-port naming

Hindawi is the programming-system family. The language-named implementations are ports/specializations of that system: Chintamani is the Telugu port of Hindawi; BangaBhasha is the Bangla port. They should not be modeled as unrelated tools or as components that merely contain Hindawi. The relationship is a language-scoped specialization (is-a/port-of), while individual Shaili frontends describe programming-language paradigms such as LOGO, BASIC, C, C++, assembly, Lex and Yacc.

This relationship statement is project-owner clarification supplied for this documentation task. The public web sources below corroborate the broader Hindawi family and historical Shaili Robot, but do not independently establish the Chintamani/BangaBhasha naming lineage.

Chronology: oldest to latest

  1. 15 August 2004 — reported initial public release. The date is repeated by the Hindawi Programming System overview. This is a retrospective secondary source, not a contemporaneous release artifact. Overview.
  2. 15 August 2005 — reported version 2 release. The same overview says it was released by Bihar's then former education minister Ram Prakash Mahto. Treat as a reported historical date pending an original release package or announcement. Overview and cited references.
  3. 20 November 2005 — project blog introduces Hindawi. The Hindawi blog has an entry titled “Haven't you heard of Hindawi???” dated 20 November 2005. Hindawi project blog.
  4. 17 December 2005 — detailed project description. The blog describes C, C++, Lex, Yacc, assembly, BASIC, LOGO and Java equivalents in Hindi, Bangla and other Indian languages; it also discusses script display, conversion filters and translation between Indic and English programming forms. Hindawi project blog, 17 December 2005 entry.
  5. 28 December 2005 — SourceForge registration. SourceForge lists the project as registered on this date and describes it as an open-source suite of vernacular programming languages, including LOGO. SourceForge project page.
  6. 16 August 2006 — reported Linux port. The overview associates the Linux port with a Sarai fellowship. The project blog and later coverage describe a Linux version and the Lekhak IDE. Overview · Project blog.
  7. March 2007 — Linux Magazine coverage. A Linux Magazine “Linux World News” page identifies Shaili Robot as LOGO and lists the Shaili family: Guru (C), Shraeni (C++), Kritrim (OpenJava/JVM), Shabda (Lex), Vyaaka (Yacc), Yantrik (x86 assembly), Prathmik (BASIC), and Robot (LOGO). It describes translation to an English counterpart and GCC as backend for the compiled languages. This is the strongest located contemporary third-party source in this search. Linux Magazine PDF, issue 76, March 2007, p. 12.
  8. 10 April 2008 — SourceForge archive snapshot. SourceForge's old-files listing includes hindawilinux.tgz dated 10 April 2008, and the project files page lists the Hindawi@Linux package. These establish an archived package listing, not a successful build on modern systems. OldFiles · Files.
  9. 26 April 2014 — last-update metadata shown by SourceForge. The project page reports “Last Update: 2014-04-26.” This is hosting metadata, not proof of source changes or an active release on that date. SourceForge project page.
  10. 4 September 2024 — overview page revision. The currently accessible Wikipedia page says it was last edited on 4 September 2024 and explicitly carries sourcing warnings. Use it as a discovery/index source, not as sole authority. Hindawi Programming System overview.
  11. Current archive/repository work — Romenagri and multilingual recovery. The current working archive includes Hindawi/Romenagri specifications, language-port audit material and Shaili language specification pages. These are modern reconstruction and test artifacts, not evidence that all historical ports are already reproduced. Romenagri repository.

What the sources establish

  • Hindawi was described as an open-source suite of localized programming languages, not just an educational toy.
  • Public descriptions explicitly include LOGO under the name Shaili Robot.
  • The described HPS pipeline translates localized source into a compiler-acceptable counterpart and then uses existing compiler/toolchain components.
  • Contemporary sources list a broad Shaili family and mention Hindi/Bangla language coverage; source availability and feature parity still require artifact-level verification.

Evidence quality and unresolved work

The sources are a mix of the project's own blog, SourceForge metadata, one contemporary magazine item, and a later overview that warns it has sourcing problems. A defensible chronology should preserve these source types rather than treating every repeated date as independently verified.

  • Recover the original Shaili Robot/LOGO source, localized command tables, samples and build instructions.
  • Establish exact language/script profiles supported by each release.
  • Verify Chintamani and BangaBhasha lineage from their own repositories, source headers, release artifacts or dated announcements.
