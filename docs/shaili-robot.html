Shaili Robot

A server-free browser demonstrator for the Shaili Robot paradigm: LOGO-like turtle graphics that can also serve as a programming interface for robots. This page implements an explicitly bounded subset, not a recovered clone of the historical frontend.

Commands are parsed as tokens, not evaluated as JavaScript. Comments begin with ; and continue to the end of the line. REPEAT n [ ... ] supports nested blocks.

Supported command subset

CommandAliasesEffect
FORWARD nFD nMove forward by n units.
BACK nBK nMove backward by n units.
RIGHT nRT nTurn clockwise n degrees.
LEFT nLT nTurn counter-clockwise n degrees.
PENUPPUMove without drawing.
PENDOWNPDResume drawing.
HOME—Return to the centre and face north without clearing the drawing.
CLEARSCREENCSClear drawing and reset turtle.
REPEAT n [ ... ]—Repeat a nested block; n must be 0–1000.
SETPENCOLOR name—BLACK, BLUE, RED, GREEN, ORANGE, PURPLE or #RRGGBB.
SETHEADING n—Set heading in degrees clockwise from north.

Scope: This is a deliberately small teaching subset. It does not yet implement variables, procedures, arithmetic expressions, interactive input, or full historical Shaili Robot syntax.

Relationship to historical Hindawi

Contemporary public descriptions identify Shaili Robot as Shaili Robot, part of the Hindawi programming suite, with localized frontend translation to a compiler-acceptable counterpart as the broader HPS mechanism. This page is a new static-browser teaching and smoke-test surface; it does not claim compatibility with archived Shaili Robot source, its localized keyword vocabulary, or its original backend.

To establish parity, vendor and inspect the historical LOGO frontend, its native-script/Romenagri filters, sample programs, exact translator/backend versions, and license. Then add fixtures before enabling localized aliases. Do not infer Telugu or Bangla commands from the C/C++ ports.
